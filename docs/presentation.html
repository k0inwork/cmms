Wind CMMS

Hybrid Service-Asset Platform for Remote Wind Turbine Inspection & Repair

Engineering Briefing — Confidential

The Problem Today

Field Operations

  • Spreadsheets + email to coordinate inspections
  • Photos on shared drives, not linked to assets or tickets
  • No offline capability — remote sites have unreliable connectivity

Workforce Management

  • Sick technician? Phone calls + Slack to find replacement
  • No system to match skills, certs, proximity
  • Missed inspection on a known defect = emergency repair

Traceability Gap

  • No chain from defect → inspection → repair → evidence → report
  • Cannot reproduce reports from stored data
  • No audit trail for compliance

Architecture Overview

Six Core Capabilities

1. Offline-First PWA (Phase 2)

  • Service Worker + IndexedDB
  • Briefcase model: pre-load before site visit
  • Full offline capture, auto-sync on return

2. Conflict Resolution

  • Field-level merge for inspections
  • State machine for ticket transitions
  • Sequence number versioning for safety data

3. Dynamic Templates

  • JSON schema inspection forms
  • No app update to add new inspection types
  • Versioned — old inspections keep their template

4. Absence → Replacement

  • Weighted scoring: skills 30%, certs 25%, proximity 20%
  • Minimum 60% threshold
  • Ranked candidates with reason codes

5. Evidence Lifecycle

  • Capture → Tag → Sync → Review → Approve
  • Original files never modified
  • Presigned S3 URLs for upload

6. Full Audit Trail

  • Append-only, never deleted or modified
  • Every state change, approval, assignment
  • Compliance-ready

Core Data Model

Every record links to an asset, a user, and a point in time. Full traceability.

A Day in the Life: Field Technician

Morning (at hotel, WiFi available)

  • Opens PWA on company tablet → syncs overnight queue
  • System pre-loads today's assigned inspections + asset data + templates
  • Sees 3 blade inspections at Wind Farm Alpha, WTG-04, WTG-07, WTG-12

On Turbine (no signal)

  • Opens first inspection → dynamic form renders from JSON template
  • Fills pass/fail checks, enters crack measurements (mm), taps to capture photos
  • Photos tagged automatically: asset=WTG-07/Blade-A, inspection=INS-2026-0041
  • Marks severe trailing edge crack → app auto-flags defect as "critical"
  • All data saved to IndexedDB with sync status: pending

Back at vehicle (signal returns)

  • App auto-syncs: 3 inspections + 14 photos + 2 video clips
  • Evidence uploads to S3 via presigned URLs, metadata to API
  • Critical defect auto-creates ticket, assigns to site lead
  • Status flips to synced

A Day in the Life: Dispatcher

08:00 — Morning Check

  • Opens dispatch board → sees today's 12 assignments across 3 sites
  • Coverage view shows: Site Alpha = 3 techs (green), Site Bravo = 1 tech (amber)

09:15 — Technician Calls in Sick

  • Marks technician "Sick" → system records absence (reason, expected return)
  • System finds 2 open assignments now uncovered
  • Auto-calculates SLA impact: "Bravo WTG-15 inspection due Thu, now at risk"
  • Replacement engine runs: ranks 4 candidates by weighted score

09:20 — Reassignment

  • Candidate #1: Maria — 87% match (skill 100%, cert 80%, proximity 90%, workload 70%, site familiarity 95%)
  • Dispatcher reassigns with one click → Maria gets push notification
  • Schedule updates, coverage view returns to green

15:00 — Critical Defect Alert

  • Notification: "Critical defect on WTG-07 Blade-A — trailing edge crack 120mm"
  • Creates emergency work order, assigns repair crew, SLA clock starts
  • Full audit trail records every action

Deployment Topology

Security Model

Authentication & Authorization

  • Auth: Custom JWT (access 15m + refresh 7d with rotation)
  • RBAC: 5 roles (tech, QA, dispatcher, ops manager, admin)
  • Multi-tenant: Organization-scoped queries (WHERE organization_id = ?)
  • Phase 2+: SSO (Google, Microsoft, LDAP, SAML)

Data Protection

  • At rest: PostgreSQL encryption
  • In transit: TLS 1.3 everywhere (API)
  • Phase 2+: S3 server-side encryption, encrypted local storage on device
  • Secrets: Environment variables, never in source code
